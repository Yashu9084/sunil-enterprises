Noto Sans Devanagari is vendored from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/notosansdevanagari

The font is used for Hindi/English PDF shaping. Its SIL Open Font License is in
OFL.txt. It was downloaded over verified HTTPS on 2026-10-23 and is included in
the source, so builds do not download fonts or depend on a third-party font CDN.
